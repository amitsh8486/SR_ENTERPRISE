# Image prompts for S R Enterprise

The site currently shows SVG illustrations for wood species and finished-product categories, plus two real CC0 photos (hero, round logs, band). To replace an illustration with a photo, save the new file in `assets/images/` and change the `src` in `index.html` (for example `species-sal.svg` to `species-sal.jpg`). Keep the same aspect ratio: 4:3 for species, roughly 6:5 for products, 3:2 for logs.

Use this style suffix on every prompt: "natural daylight, warm neutral colour grading, sharp focus, no people, no text, no watermark, professional product photography, shallow depth of field".
